What I build once we know

When the answer is a sales motion, I build it in four layers with one job each. The failure mode with four tools is two of them doing the same job badly, so the boundaries come first.

LayerIts one job
SourcingFind candidates and send sequences
GateEnrich, score, and decide who is contactable
RecordEvery cleared company, and everything that happens to it
CaptureNotes land on the record without anyone typing

The rules underneath matter more than the tools, which are swappable:

  • A fit score with a floor. Five criteria, twenty points each. Above the line gets contacted. Below it stays in the gate, uncontacted, as suppression memory so nobody works it twice.
  • A hard size gate before scoring, checked against enrichment data. A sourcing tool's own confidence number scores on job titles and hiring recency, which puts enterprise brands into a campaign built for 150-person companies.
  • A deal exists when a human replies. Everything before that is a company status. Cold reply rates run 3–6%, so counting sends as pipeline inflates the forecast.
  • Attribution set at record creation and never edited. The sourced-by field doubles as the commission register, so compensation questions never depend on anyone's memory.
  • Automation is a purchase. Manual export holds until volume clears roughly 500 records a week.

When the answer is pricing, I rebuild the buyer's math on the margin they keep: contribution by segment, break-even by tier as a single number, and a holdout test designed to separate real lift from noise. The buyer already has these numbers, so the pitch runs on theirs instead of yours.
